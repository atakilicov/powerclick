# Privacy

PowerClick does not collect, transmit or share any personal data. Everything the app does happens on your Mac.

- **No network requests.** There are no analytics, no telemetry, no crash reporters and no tracking code.
- **Sandboxed.** PowerClick runs in the macOS App Sandbox, so macOS itself enforces these limits.
- **Stored locally.** Clipboard history, snippets and the activity log stay in PowerClick's App Group container on your Mac. Settings stay in PowerClick's own preferences. None of it is synced to any external service.
- **Clipboard.** PowerClick reads the clipboard to build your clipboard history. With "Ignore Passwords" on, it skips items marked as concealed, such as passwords from a password manager. Clearing your history removes the stored items.
- **Finder extension.** When you right-click, the Finder extension reads the current folder path and the selected file paths to build the menu and run the action you choose.
- **Notifications.** PowerClick can show standard local macOS notifications, for example when a file is created. Nothing is sent to a server.
- **No accounts.** There is no sign-in and there are no user accounts.
- **You're in control.** Clear your clipboard history, delete individual snippets, or use "Reset All Data" in Settings to remove everything PowerClick stores.
