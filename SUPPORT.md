# Support

## Before you report

**PowerClick doesn't appear in Finder's right-click menu.**
The Finder extension has to be enabled once. Open **System Settings > Privacy & Security > Extensions > Finder Extensions** and make sure PowerClick is turned on. If it isn't listed, quit PowerClick from the menu bar, open it again, and check once more.

**The menu bar icon shows an orange dot.**
The extension is inactive. Choose "Refresh Status" in the menu bar popover. If the dot stays orange, check that the extension is still enabled in System Settings. macOS sometimes turns extensions off after a system update, and turning it back on fixes it.

## Report a bug

[Open a bug report](https://github.com/atakilicov/powerclick/issues/new?template=bug_report.yml). The form asks for:

- **PowerClick version.** Select PowerClick in your Applications folder and press Command-I.
- **macOS version and Mac type.** Choose Apple menu > About This Mac. "Chip" means Apple silicon, "Processor" means Intel.
- **Where the file lives:** your Mac's disk, iCloud Drive, Dropbox, Google Drive, OneDrive, Box, an external drive or a network share.
- **Steps to reproduce**, what you expected, and what happened instead.
- **A screenshot or screen recording**, if you can.

Issues are public, so leave out file names, paths and anything else you'd rather keep private.
